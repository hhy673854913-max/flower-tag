# 花艺图库

面向花艺师的微信作品图库：上传作品照片，经内容安全检测和视觉模型分析生成六维标签，人工确认后入库，再按标签检索并分享作品。

> 本文以 2026-11-23 的本地代码为准。代码实现、云端部署、真机验收和正式发布是四种不同状态，不能相互替代。

## 1. 当前能力

- **账号与权限**：校验码开通花艺师；管理员由服务端白名单识别；作品按微信 OPENID 隔离。
- **作品入库**：相册或拍照，单次最多 9 张；主图和附加图均须通过图片安全检测，AI 结果须人工确认。
- **六维整理**：颜色、色系、花材（主花／辅花／叶材）、种类、风格、用途；新写入数据由服务端校验。
- **找图与管理**：三列作品墙、组合筛选、详情编辑、最多 8 张附加图、个人统计和自定义花材。
- **分享展示**：单件分享、全部／精选作品集、作品集标题与描述、极简花艺名片；访客只读。
- **公共能力**：四类可配置公告、意见反馈、关于与隐私说明。
- **运行保障**：上传任务台账、幂等保存、取消与离页回收、会话缓存、图片 URL 鉴权签发。

## 2. 技术结构

原生微信小程序（JavaScript／WXML／WXSS）＋ 微信云开发。前端不直接读写业务数据库，云端身份统一取自真实 OPENID。

## 3. 本地运行

1. 用微信开发者工具导入项目根目录，使用支持云开发的正式 AppID。
2. 在 `miniprogram/app.js` 将 `globalData.envId` 设为目标云环境 ID。
3. 在同一云环境准备下表集合，业务集合均禁止客户端直接读写。
4. 部署云函数及依赖，配置环境变量、数据库索引、存储规则和定时器。
5. 重新编译；真机预览前完成云端与权限检查。

### 当前业务集合

| 集合 | 用途 |
| --- | --- |
| `accessAccounts` | 账号、校验码状态、写版本及上传／作品集授权版本；也保存码池锁文档 |
| `records` | 作品、六维标签、主图与附加图引用、单件分享状态 |
| `tags` | 本人自定义花材；使用次数由作品实时聚合 |
| `admins` | 可选管理员名单，匹配 `openid` 字段 |
| `shareLinks` | `type: portfolio` 作品集授权及文本元数据 |
| `feedbackRecords` | 私有意见反馈，仅云函数写入 |
| `uploadJobs` | 上传 session／image 台账、审核摘要、幂等状态与回收信息 |

`florists`、`floristApplications` 仅出现在历史数据运维兼容范围，不是当前名片或账号链路的数据源。

## 4. 部署要点

### 4.1 云函数

建议先部署 `accessGate`，再部署 `imgSecCheck`、`analyzeImage` 和需要运维时的 `adminMaintenance`。均使用云端安装依赖。

- `accessGate` 额外依赖 `@cloudbase/node-sdk:2.9.1`，不要只上传 `index.js` 而遗漏同目录模块。
- `imgSecCheck` 依赖 `jimp` 和 `image-size`；其 `config.json` 声明 `security.imgSecCheck` 和 60 秒超时。
- `accessGate` 声明 `security.msgSecCheck`、60 秒超时及 `reapUploadJobs` 定时器。
- `analyzeImage` 默认使用 Qwen；只配置 Kimi 密钥但不会自动切换提供方。完整变量见[环境变量](./环境变量.md)。

### 4.2 存储与回收

- 按 `cloud-storage.rules.json` 配置自定义存储规则：客户端不可直接读，只能写本人登记的暂存路径；正式 `sealedFiles/` 由服务端写入。
- `reapUploadJobs` 使用 `0 */10 * * * * *`；平台 Timer 的 `CustomArgument` 必须与 `accessGate.UPLOAD_GC_TOKEN` 一致。
- 重新部署或重建触发器后，复核定时器、令牌绑定和原环境变量；不要在日志中打印秘密。
- 索引必须按真实查询核对，尤其是本人作品双排序、作品集 `_id` 扫描、上传台账查询和 `analyzeImage` 的任务查找。具体联动见[修改影响范围清单](./修改影响范围清单.md)。

## 7. 当前边界

- 名片只展示名字、授权范围和作品数；没有头像、联系方式、二维码、海报或名片资料编辑器。
- 没有关键词／自然语言搜索、完整产品事件统计、公共大厅、跨花艺师聚合、排行或交易能力。
- 作品集公开翻页会重新扫描并内存排序，大规模性能需在目标云环境验证。
- 文档中的历史“已上线”“已部署”和运营指标不是本次代码核对的结论；当前云端状态须在控制台另行确认。
