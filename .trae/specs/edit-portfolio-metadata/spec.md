# 作品集标题与描述编辑规格

## 为什么

当前已创建的作品集卡片只显示「全部作品／精选作品」及固定范围说明，多个分享集难以区分。花艺师需要为每个分享集设置独立标题和描述，并让接收方看到对应介绍。

## 变更内容

- 在「已创建的作品集」有效链接卡片中新增「编辑标题与描述」入口，提供标题输入、描述输入、字数提示、保存和取消。
- 卡片主标题展示自定义标题，描述展示自定义介绍；全部／精选标识及固定范围说明独立保留，不能被自定义内容覆盖。
- 作品集分享页展示自定义标题和描述，同时保留作者名字、范围、数量和只读作品网格；微信分享卡片优先使用自定义标题。
- 修改只更新当前分享集的文本，沿用原令牌、作品范围、创建时间和分享状态；重新打开或刷新原链接读取最新内容。
- 服务端执行本人权限、长度及文本内容安全检查；兼容无标题和描述的既有作品集。
- 创建全部／精选链接的现有流程保持原有默认文案，创建后可以编辑。本次不增加创建前填写流程。

## 影响范围

- 关联既有规格：`add-florist-portfolio-sharing` 已完成本地实施；本次独立增量规格，不重置既有验收或据历史勾选推定云端部署完成。
- 页面：`miniprogram/pages/portfolio-manage/portfolio-manage.js/wxml/wxss`、`miniprogram/pages/portfolio-share/portfolio-share.js/wxml/wxss`。
- 接口：`miniprogram/utils/api.js`、`cloudfunctions/accessGate/portfolio.js`、`cloudfunctions/accessGate/index.js` 的审核依赖、接口分发及错误提示。
- 数据：`shareLinks` 的 `type:'portfolio'` 文档增加可选 `title`、`description`、`updatedAt`；不复制作品，不修改账号名字，不迁移未知历史类型。
- 配置：复用已有 `security.msgSecCheck` 权限，无预设新增集合、索引、环境变量或页面路由。须核对函数配置与目标环境审核能力。
- 上下游：创建、本人链接分页、停止、撤销版本、公开列表、详情、原图、默认微信分享回调及个人缓存。
- 文档：实施前维护 `修改影响范围清单.md` 的 2.11 节；实施后同步需求、开发日志、代码说明、功能说明、技术规范，检查 README 和环境变量说明。
- 保留当前原生微信 JS/WXML/WXSS 与云开发结构，不部署、发布或改线上数据。

## 新增需求

### 需求：本人分享集独立编辑

系统必须允许有效花艺师及管理员编辑本人仍有效的作品集标题和描述，管理员不能代替他人编辑。

#### 场景：打开与保存编辑

- **当**作者在有效作品集卡片点击「编辑标题与描述」
- **则**显示该链接的当前文本，标题缺失时预填「全部作品」或「精选作品」，描述缺失时为空。
- **则**标题为去除首尾空白后的 1～40 字单行文本，描述为去除首尾空白后的 0～300 字文本，保留内部换行；描述允许清空。
- **则**前后端统一按 Unicode 码点计数，不能截断超限输入后保存；服务端拒绝错误类型、超限和标题换行等无效参数。
- **当**文本校验、内容安全检查和本人有效授权全部通过
- **则**原子保存标题、描述及更新时间，更新当前卡片，显示保存成功；描述清空后不显示空白描述区域。
- **则**标题、描述按纯文本显示，不解释为 HTML 或富文本。

#### 场景：取消与失败

- **当**作者取消
- **则**不写入、不改变原卡片。
- **当**校验不通过、内容审核拒绝、网络失败或审核服务异常
- **则**不写入任何一项，显示可理解的错误并保留输入供修改或重试；重复点击不会重复提交。
- **当**页面隐藏、卸载或账号失效
- **则**旧请求不能回写新页面状态，身份失效时关闭编辑并清除旧作者草稿。

### 需求：文本写入权限与审核

系统必须只允许真实调用者更新自己的有效作品集，并在新文本向接收方展示前执行服务端内容安全检查。

#### 场景：有效本人更新

- **当**请求携带作品集 ID、标题与描述
- **则**服务端检查真实调用者的开通／管理员状态、非清理状态及链接本人归属、类型、enabled 和账号作品集授权版本。
- **则**仅允许更新文本白名单字段；忽略或拒绝客户端附带的 token、ownerOpenid、mode、recordIds、enabled、portfolioVersion 等管理字段。
- **则**复用既有微信 `security.msgSecCheck` 能力审核完整标题和非空描述，仅明确通过后写入；审核拒绝及异常均不放行。
- **则**审核在写事务前完成，写入仍复用账号事务，事务内重新核对链接归属及有效状态。

#### 场景：停止、撤销或越权

- **当**链接已停止、版本已失效、账号被撤销／清理中，或者请求指定他人链接
- **则**拒绝更新；审核期间发生停止或撤销，也不能在其后提交有效修改或恢复链接。
- **则**失效卡片保持只读；需要分享时继续按原规则创建新链接。
- **当**多个合法编辑同时发生
- **则**最后成功提交的完整标题和描述生效，不出现只保存其中一项的混合结果。

## 修改需求

### 需求：作品集管理卡片与分享展示

系统必须在保留作品集授权范围与作者信息的同时，展示每个分享集的自定义标题和描述。

#### 场景：管理卡片

- **当**本人分页读取已创建链接
- **则**返回标题、描述及更新时间等文本展示字段，卡片主标题优先显示自定义标题。
- **则**描述不为空时显示自定义描述；全部／精选标识、创建时间、状态和「后续新增作品自动展示／仅展示创建时选中的作品」仍独立展示。
- **则**编辑单个分享集不改变其他链接、顺序、分页游标或原有预览／再次分享／停止行为；卡片仍按创建时间排序。

#### 场景：接收方打开与转发

- **当**作者或接收方打开、刷新或重新进入有效作品集
- **则**从服务端读取最新标题和描述，自定义标题为页面主标题，作者名字另行展示；描述保留换行并适应长文本。
- **当**从有效作品集页分享给好友
- **则**卡片标题使用自定义标题，无自定义标题时使用「作者名字的花艺作品集」；路径仍指向原令牌，封面继续取授权缩略图。
- **则**描述展示在作品集页面，不能承诺微信分享卡片提供独立描述字段；已发送的微信卡片标题不承诺追溯刷新，打开原链接可读取最新内容。
- **则**详情、原图仍只读并逐次鉴权，标题编辑不开启任何单件分享。

#### 场景：既有链接兼容

- **当**既有有效作品集缺少新字段
- **则**管理卡片继续展示「全部作品／精选作品」，分享页和分享卡片继续使用原作者默认标题，不显示描述。
- **则**缺少文本字段不会令原链接失效；不批量回填旧文档，不改变未知历史类型。
- **当**新增文本字段格式异常
- **则**展示安全的默认文本，不回传未经规范化的对象等值，不因此扩大授权范围。

## 接口约定

- 新增 `accessGate` action：`updatePortfolioMetadata({ id, title, description }) -> { ok, id, title, description, updatedAt }`，失败沿用 `ok:false/error` 包装。
- `listPortfolioShares` 的每条管理摘要增补 `title`、`description`、`updatedAt`；缺失自定义文本返回空字符串，界面按场景生成默认标题。
- `readPortfolioShare` 增补 `title`、`description`，保留现有 `name/mode/total/records/nextCursor/hasMore`；公开文本按白名单规范化，末次鉴权使用当前有效链接文本。
- `createPortfolioShare`、`stopPortfolioShare`、`readPortfolioRecord` 的既有调用协议保持兼容，不因文本编辑改令牌或作品引用。
- `shareLinks.title/description/updatedAt` 只由服务端写入，客户端数据库权限继续关闭；文本字段不参与筛选或排序，不需要专用索引。
- 审核错误必须准确描述作品集文本问题，不能沿用误导性的「名字审核未通过」提示；原账号名字审核行为保留。

## 移除需求

无。先前规格「不新增作品集标题等输入」的范围限制由本增量明确扩展；名片、头像、联系方式、海报、公共大厅及访问统计仍不在本次范围内。

- 批准后实施代码及维护文档，模拟验证、原生编译与云端／真机实测分别记录。
- 需要更新部署 `accessGate` 并编译／发布前端；本规格不执行部署、发布、线上权限或索引变更。
